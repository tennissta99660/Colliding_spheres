# Colliding_spheres
A fast-paced survival game where you control a sphere in an arena, dodging enemy spheres that try to knock you out. The challenge increases as more enemies spawn with every round! Use booster rings to turn the tide and eliminate enemies instantly.

## 🎮 Features
- **Survival Gameplay** – Stay in the arena while avoiding enemies.
- **Dynamic Difficulty** – Each time you survive, more enemies spawn.
- **Booster Rings** – Gain temporary invincibility to knock out enemies instantly.
- **Random Spawning** – Enemies and booster rings appear randomly for unpredictable gameplay.

## 🎮 How to Play
- **Move:** Use `WASD` or `Arrow Keys` to control your sphere.
- **Survive:** Avoid getting knocked out of the arena by enemy spheres.
- **Knock Out Enemies:** If an enemy falls off, a new wave spawns with `i+1` enemies.
- **Booster Rings:** Collect them to gain a temporary ability to knock out enemies instantly.

## 🔥 Technologies Used
- **Unity** – Game engine
- **C#** – Game logic and mechanics
- **Physics Engine** – Realistic movement and collisions
